# 每日词记

考研英语一阅读与翻译词汇打卡网页。使用原生 HTML、CSS 和 JavaScript，手机和电脑都可直接访问。

- 核心 50 词、九个分类和按中英文搜索的词库。
- 点击单词卡显示释义。选择「认识」或「不认识」即计入今日练习，同一词条每日最多计一次。
- 默认目标 20 词，可切换为 10、30 或 50。达到目标自动打卡。词卡、错词、学习进度和打卡记录保存在当前浏览器。
- 词表来自提供的备考词汇资料。合并同分类下重复的 intellectual 释义，保留不同分类下 address 的不同用法，两张卡共享掌握状态。核心 50 词根据做题用途选取。

## GitHub Pages

1. 将本目录文件推送到 GitHub 仓库的 main 分支。
2. 打开仓库的 Settings → Pages。
3. 在 Source 选择 Deploy from a branch，分支选择 main，文件夹选择 /(root)，然后保存。
4. 部署完成后，打开 Pages 设置显示的网站链接。

在手机 Safari 中，可从「分享」菜单将页面添加到主屏幕。
